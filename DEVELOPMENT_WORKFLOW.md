# Development Workflow

For every task:

1. Read:
   - AI_RULES.md
   - PROJECT_CONTEXT.md
   - BUSINESS_RULES.md
   - REQUIREMENTS.md

2. Understand the relevant files.

3. Explain the implementation plan.

4. Modify ONLY the required files.

5. Keep changes as small as possible.

6. Verify:
   - No TypeScript errors
   - No build errors
   - Existing functionality still works
   - Responsiveness remains intact

7. Summarize:
   - Files changed
   - Why they changed
   - Potential risks

8. STOP.

Wait for user approval before continuing.
