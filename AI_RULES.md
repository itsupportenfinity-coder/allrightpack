# AI Rules

Before making ANY changes:

- Read this file completely.
- Read PROJECT_CONTEXT.md.
- Read REQUIREMENTS.md.

## General

- Think before coding.
- Never guess.
- Understand the project before modifying anything.
- Preserve the existing React architecture.
- Preserve TypeScript.
- Preserve Tailwind.
- Never redesign the website.
- Never change unrelated files.
- Never delete existing features without permission.
- Explain significant architectural decisions before implementing them.

## Code Quality

- Keep components reusable.
- Avoid duplicate code.
- Keep code readable.
- Use TypeScript best practices.
- Follow React best practices.

## UI

- Preserve existing branding.
- Maintain green + white color scheme.
- Keep animations subtle.
- Improve trust.
- Improve readability.
- Improve usability.
- Never make the website look AI-generated.

## Performance

- Optimize images.
- Optimize rendering.
- Minimize unnecessary re-renders.
- Target Lighthouse >95.

## Accessibility

- Follow WCAG.
- Proper ARIA labels.
- Keyboard navigation.
- Semantic HTML.

## Workflow

Always follow this order:

1. Understand
2. Analyze
3. Explain
4. Plan
5. Modify
6. Verify
7. Stop and wait for approval
